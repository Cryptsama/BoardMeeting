BoardMeeting – Dual AI Room (ChatGPT + Gemini)
=============================================

Quick Start (Windows)
---------------------
1. Open this folder.
2. Edit the ".env" file and put your real keys:
   - OPENAI_API_KEY=...
   - GEMINI_API_KEY=...
3. Double-click "start.bat".
4. When it says "Starting BoardMeeting on http://localhost:8000 ...",
   open your browser to: http://localhost:8000

Usage
-----
- Type a message in the box and press Enter.
- ChatGPT and Gemini will both see the whole room history and
  briefly react to each other before answering you.
